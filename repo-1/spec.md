# spec.md — דאשבורד ניטור מכונות ייצור

## 1. מטרה
דאשבורד ניהולי לבעל המפעל, שמציג בזמן אמת את התפקוד של שלוש מכונות הייצור: כמה זמן כל מכונה עבדה, כמה עובדים מאוישים עליה, מה מיוצר בה, כמה יוצר ומה הפחת. המסך נועד להחלטה מהירה במבט אחד — לא לדוח מפורט.

## 2. משתמש יעד
- **בעל העסק** — משתמש יחיד, לא טכני. צופה בדאשבורד מהמשרד (דסקטופ) ומרצפת הייצור (נייד).
- אין ניהול הרשאות מורכב בשלב הראשון: משתמש אחד, התחברות פשוטה.

## 3. המכונות
| # | שם מכונה | מזהה פנימי |
|---|-----------|------------|
| 1 | מכונת כנול | `knol` |
| 2 | מכונת רונדו | `rondo` |
| 3 | מכונת קרומסטר | `kromster` |

## 4. נתונים נמדדים (לכל מכונה)
| שדה | סוג | תיאור | חובה |
|------|-----|--------|------|
| `machineId` | enum | knol / rondo / kromster | כן |
| `workMinutes` | number | זמן עבודה מצטבר במשמרת (דקות) | כן |
| `workersCount` | integer | מספר עובדים המאוישים על המכונה | כן |
| `productName` | string | שם המוצר המיוצר כרגע | כן |
| `producedQty` | number | כמות מיוצרת (יחידות) | כן |
| `wasteKg` | number | פחת ייצור בק"ג | כן |
| `status` | enum | פעילה / בעצירה / בתחזוקה | כן |
| `shiftDate` | date | תאריך המשמרת | כן |
| `updatedAt` | datetime | זמן עדכון אחרון | כן |

### נתונים נגזרים (מחושבים, לא נשמרים)
- **תפוקה לשעה** = `producedQty / (workMinutes / 60)`
- **תפוקה לעובד** = `producedQty / workersCount`
- **אחוז פחת** = `wasteKg / (wasteKg + משקל מיוצר)` — או, אם אין משקל ליחידה, פחת ק"ג ל־100 יחידות
- **ניצולת זמן** = `workMinutes / אורך המשמרת`

## 5. מסכים

### 5.1 מסך ראשי — סקירה
- **שורת סיכום עליונה (KPI)**: סה"כ יחידות שיוצרו היום · סה"כ פחת בק"ג · סה"כ שעות עבודה · מספר עובדים פעילים.
- **שלושה כרטיסי מכונה** (כנול / רונדו / קרומסטר), כל כרטיס מציג:
  - שם המכונה + נורית סטטוס (פעילה / עצורה / תחזוקה)
  - שם המוצר המיוצר
  - זמן עבודה (שעות:דקות)
  - מספר עובדים
  - כמות מיוצרת
  - פחת בק"ג + אחוז פחת
  - כפתור גדול: **עדכון נתונים**
- **בורר טווח זמן**: היום / השבוע / החודש — ככפתורים גדולים, לא dropdown.

### 5.2 מסך עדכון נתוני מכונה
טופס פשוט, שדה אחד מתחת לשני, שדות קלט גדולים: שם מוצר, זמן עבודה, מספר עובדים, כמות מיוצרת, פחת ק"ג, סטטוס. כפתור שמירה ברוחב מלא.

### 5.3 מסך השוואה
- גרף עמודות: כמות מיוצרת לפי מכונה.
- גרף עמודות: פחת בק"ג לפי מכונה.
- גרף קו: תפוקה לאורך זמן (7 ימים אחרונים).
- טבלת השוואה: מכונה × (תפוקה לשעה, תפוקה לעובד, אחוז פחת, ניצולת זמן).

## 6. דרישות עיצוב

### כללי
- **שפה**: עברית, כיוון `rtl` לכל הממשק.
- **צבעוניות בוהקת** — צבעים רוויים וחזקים, ניגודיות גבוהה, קריא גם בתאורת מפעל.
- **אסור צבע ורוד** בשום גוון (כולל magenta / rose / fuchsia) — לא ברקעים, לא בגרפים, לא בסטטוסים.
- **כפתורים גדולים**: גובה מינימלי 56px, טקסט 18px ומעלה, אזור מגע מינימלי 48×48px.
- מספרים גדולים ובולטים — המספר הוא הגיבור של המסך, לא התווית.
- אייקונים ברורים לצד כל מדד.

### רספונסיביות
- **דסקטופ (≥1024px)**: שלושת כרטיסי המכונות זה לצד זה, KPI בשורה אחת של 4.
- **טאבלט (768–1023px)**: שני כרטיסים בשורה, KPI 2×2.
- **נייד (<768px)**: עמודה אחת, כרטיס מתחת לכרטיס, KPI 2×2, כפתורים ברוחב מלא, ללא גלילה אופקית.
- נבנה mobile-first.

## 7. ארכיטקטורה טכנית
- **Frontend**: React + TypeScript, Vite.
- **עיצוב**: Tailwind CSS (כיוון RTL מופעל).
- **גרפים**: Recharts.
- **Backend**: Node.js + Express.
- **מסד נתונים**: SQLite בשלב ראשון (קובץ מקומי), ניתן להחלפה ל־PostgreSQL.
- **State**: React Query לשליפת נתונים, רענון אוטומטי כל 60 שניות.

### מודל נתונים
```sql
CREATE TABLE machines (
  id          TEXT PRIMARY KEY,   -- knol | rondo | kromster
  name        TEXT NOT NULL,
  color       TEXT NOT NULL
);

CREATE TABLE production_logs (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  machine_id    TEXT NOT NULL REFERENCES machines(id),
  shift_date    DATE NOT NULL,
  product_name  TEXT NOT NULL,
  work_minutes  INTEGER NOT NULL CHECK (work_minutes >= 0),
  workers_count INTEGER NOT NULL CHECK (workers_count >= 0),
  produced_qty  REAL NOT NULL CHECK (produced_qty >= 0),
  waste_kg      REAL NOT NULL CHECK (waste_kg >= 0),
  status        TEXT NOT NULL,    -- running | stopped | maintenance
  updated_at    DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### API
| Method | Endpoint | תיאור |
|--------|----------|--------|
| GET | `/api/machines` | רשימת המכונות |
| GET | `/api/dashboard?range=today\|week\|month` | נתוני הדאשבורד המסוכמים |
| GET | `/api/logs?machineId=&from=&to=` | רשומות ייצור |
| POST | `/api/logs` | הוספת רשומת ייצור |
| PUT | `/api/logs/:id` | עדכון רשומה |
